# DearDairy 🌙

> 一个关于 AI 日记、长期人格观察与自我理解的网页原型。

**项目状态：已停止继续开发。** DearDairy 不是准备商业化或大规模推广的产品。这个网页原型只是一个载体，用来把我在 AI 出现之后对“理想日记”的想象具体呈现出来。

**[English README →](./README.md)**

## 真正想探索的问题

DearDairy 最重要的并不是“在网页上写日记”，而是探索：

> AI 能否从一个人的长期日记中发现反复出现的行为模式，帮助其形成一份持续变化、但由本人确认的人格描述？

人不仅渴望表达，也渴望被理解、被读懂、被解析。普通日记保存表达，却不会回应；普通 AI 对话可以即时回应，却不一定能清楚呈现一个人几个月或几年间的变化。

DearDairy 尝试连接这两件事。

## 核心设计

```text
初始问卷 → 第一版 Persona
长期日记 → AI 提出行为观察
用户确认、修改或拒绝
反复出现且经确认的观察 → 长期人格描述
```

这里最重要的原则是：**日记是证据，AI 的解析只是推测。** AI 不应该擅自定义用户；只有本人确认过的观察，才可以进入长期 Persona。

日记后的反思问题也应当温和、具体、允许不回答。它的作用是邀请用户多看一眼自己的情绪、动机或矛盾，而不是用打卡、完成率或绩效语言制造自责。

## 关于这个原型

原型使用 React、FastAPI、PostgreSQL 和兼容 OpenAI API 的模型接口构建，包含日记、AI 反思问题、阶段复盘、Persona 版本和观察确认等实验性功能。

网站只是当时最容易实现的载体，并不是对日记形态的最终判断。我知道网页日记很难产生明确的盈利能力，也不太可能被大规模使用：相比手机 App、备忘录或直接与 AI 对话，它的使用门槛更高。因此，我没有把这个形式当成准备大力发展的产品；它的意义是承载和验证我对 AI 时代日记的设想。
